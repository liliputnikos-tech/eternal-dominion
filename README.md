# Eternal Dominion

iPhone build is `index.html` (art is embedded).

GitHub cannot serve the game until Pages is on. On your phone:

1. Open this repo's Settings, then Pages.
2. Branch: `main`, folder: `/ (root)`, Save.
3. Wait a minute, then open https://liliputnikos-tech.github.io/eternal-dominion/
4. In Safari, Share, Add to Home Screen.

Direct file: download `index.html` and open it from the Files app if Pages is not on yet.
